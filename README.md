# Лабораторная работа 2

Кроссплатформенная библиотека для вычислений над массивами целых чисел. Проект содержит статическую и динамическую библиотеки, демонстрационную программу app и модульные и интеграционные тесты.

## Сборка

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Исполняемый файл app и библиотеки находятся в каталоге `build/`.
