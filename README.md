# Лабораторная работа 2

Кроссплатформенная библиотека для вычислений над массивами целых чисел. В проекте есть статическая и динамическая библиотеки, демонстрационная программа, вариант 21 и два вида тестов.

## Сборка

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Программы после сборки находятся в каталоге `build/`: `app` и `variant_21`. Динамическая библиотека располагается рядом с ними, поэтому программу варианта можно запускать так: `./build/variant_21`. На Windows CMake собирает DLL рядом с исполняемым файлом.

Статическая библиотека в Linux называется `libarraylib.a`; динамическая — `libarraylib.so`. Имена расширений выбираются CMake для текущей платформы.

## Вариант 21

Программа обрабатывает значения 91, 93, 92, 95, 94, 96, 90, 89, 94 и 97. Она выводит минимум, максимум, среднее, медиану и количество дней с курсом выше 93. Ожидаемые результаты: 89; 97; 93,10; 93,50; 5 дней.
